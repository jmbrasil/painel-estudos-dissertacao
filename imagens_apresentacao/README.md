# imagens_apresentacao

Imagens geradas para os slides da defesa da dissertação ("Apresentação da defesa — esboço", Google Slides).

- Origem: `output/arquivos/imagens_apresentacao/` do repositório da dissertação (fgv_dissertacao_python).
- `painel/publicar_painel.py` copia esta pasta para o repositório do painel (jmbrasil/painel-estudos-dissertacao), de
  onde o Google Slides busca cada imagem pelo endereço público
  `https://raw.githubusercontent.com/jmbrasil/painel-estudos-dissertacao/main/imagens_apresentacao/<arquivo>`.
- Não edite as cópias no repositório do painel: gere ou altere aqui e publique de novo.
